# Computer-Vision-Hand-Tracking-System
A computer vision hand-tracking game called Circle Slice, inspired by Fruit Ninja 

# Link
Access this link to play the game!

# How to Play
- My game is a fruit ninja styled game but instead of fruits, there are bubbles!
- The player's objective is to slice all the circles or bubbles and obtain the highest score you can
- You have 20 seconds to slice as many fruits as you can
- To pop the bubbles, you have to make a pinching gesture with your fingers.
